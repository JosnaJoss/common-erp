# Common ERP – Business Acceptance Test Matrix

This matrix provides the complete, evidence-based verification record for all core business workflows across Common ERP.

## Evaluation Methodology & Status Legend
- **`PASS – ACTUALLY VERIFIED`**: Validated by automated PHPUnit feature tests or executed code paths with asserted database and accounting states.
- **`PARTIAL – SOME STEPS WORK`**: Core transactions execute, but critical steps (e.g. accounting capitalization, reversing entries, or reports) are missing.
- **`FAIL – INCORRECT RESULT`**: Workflow executes but produces mathematically incorrect or inconsistent ledger/inventory states.
- **`BLOCKED – CANNOT TEST SAFELY`**: Cannot be safely executed without destructive database writes on the preserved instance.
- **`NOT IMPLEMENTED`**: Workflow is absent from routes, controllers, and UI.
